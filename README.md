# 纯文本交流仓库 (Chat Sandbox)

本仓库主要用于与 AI Agent 进行纯文本交流、问答、测试和互动。

## 💬 默认交互模式

本项目默认使用 **Pure Chat Mode（纯聊天模式）**。

AI Agent 进入本仓库后，应将用户的普通自然语言消息视为聊天内容，而不是软件开发任务。

默认情况下：

* 直接通过自然语言与用户交流。
* 不编写代码。
* 不修改项目文件。
* 不创建代码修改计划。
* 不执行 pre-commit。
* 不创建 Git commit。
* 不提交或推送代码。
* 不为了完成普通聊天请求而操作仓库。

## 🎮 聊天互动

纯聊天模式可以包括但不限于：

* 普通问答
* 文字游戏
* 数字游戏
* 测试 AI 行为
* 模拟对话
* 连续互动
* 根据用户输入进行简单响应

这些行为均属于聊天，不应自动转换成软件开发任务。

例如：

> 用户：我们玩数数游戏，我发送什么数字，你就回复相同数字。

这是一个**纯聊天请求**，AI Agent 应直接参与游戏，而不是创建计划、修改文件或执行 Git 操作。

## 🛠️ 什么时候才进入开发模式？

只有用户明确要求进行软件开发或仓库操作时，才进入工程工作流，例如：

* 修改代码
* 创建文件
* 修复 Bug
* 实现功能
* 修改项目配置
* 执行开发命令
* 提交 Git commit
* 进行其他明确的仓库操作

如果用户没有提出明确的开发或仓库操作要求，则保持 **Pure Chat Mode**。
